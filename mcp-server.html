FAQ
Frequently asked questions
An MCP (Model Context Protocol) server exposes structured tools that AI assistants like Claude, GPT, or Cursor can call directly. Our Hyperliquid MCP server provides 26 tools that give AI agents deep access to Hyperliquid market data, trader analytics, behavioral cohorts, and real-time trade flow — enabling AI-native trading workflows.
MCP is an open protocol by Anthropic that lets AI models call external tools and data sources. Instead of copying data into prompts, the AI can directly query live data through structured tool calls. Think of it as a USB-C port for AI — one standard interface, many capabilities.
Behavioral cohort classification (710K+ wallets), trader profiling and ranking, real-time trade flow, liquidation heatmaps, funding rate analytics, order book depth, long/short ratios, position lifecycle tracking, and hidden gem discovery. All computed from direct clearinghouse indexing — not relayed from third parties.

The free tier includes generous rate limits suitable for personal use and prototyping. Paid plans offer higher throughput for production agent workflows, fund-level analytics, and commercial applications. Rate limits are per-API-key.
